# HyperGlow  
HyperOS灯效补完计划  
目前处于debug阶段，预期七月底竣工  

## 支持的机型：  
`{"yudi", "sheng", "uke", "muyu", "taiko", "koto", "piano", "yupei", "shuntian"}`  

## 已完成的功能：  
1.免root/root+LSP运行模式  
2.自定义灯光颜色/亮度/模式  
3.摄像头隐私灯自定义（需LSP启用模块）  
4.应用通知灯光自定义  
5.麦克风或屏幕共享实现的频谱同步  
6.自定义事件灯光效果  
7.配置文件备份与恢复
