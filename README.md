# HyperGlow  
HyperOS灯效补完计划  
目前已完成第一版APP，随缘更新中...  

## 支持的机型：  
`{"yudi", "sheng", "uke", "muyu", "taiko", "koto", "piano", "yupei", "shuntian"}`  

## 已完成的功能：  
1.免root/仅LSP/root+LSP运行模式  
2.自定义灯光颜色/亮度/模式  
3.摄像头隐私灯自定义（需LSP启用模块）  
4.应用通知灯光自定义  
5.麦克风或屏幕共享实现的频谱同步  
6.自定义事件灯光效果  
7.配置文件备份与恢复  

## 待实现的功能：

3.预设快捷切换  
n.欢迎提出意见
